# T-Invest Portfolio Auditor: Концепция, ТЗ и Сократовский протокол обучения

---

## 1. Концепция и ценность продукта

**T-Invest Portfolio Auditor** — это финтех-микросервис и персональный аналитический ассистент частного инвестора с интерфейсом в Telegram. 

### Бизнес-задача
Стандартные брокерские приложения показывают лишь баланс и общую доходность. Сервис решает проблему неосознанного риска частного инвестора:
* **Анализ концентрации и диверсификации:** выявление опасных перекосов в портфеле (например, >50% в одном эмитенте).
* **Математика риска (NumPy):** расчет максимальной исторической просадки (Max Drawdown), волатильности и коэффициента Шарпа.
* **Календарь денежных потоков:** своевременные уведомления о дивидендных отсечках и купонных выплатах.
* **ИИ-сводка (LLM с Pydantic):** ежедневный утренний дайджест факторов влияния на портфель без лишнего информационного шума.

### Инженерная ценность для резюме (Т-Банк / Middle Backend)
* **gRPC и Protocol Buffers:** прямая интеграция с официальным `tinkoff-invest-api` через бинарные протоколы и стримы.
* **Финансовая точность (Zero Float):** запрет на `float` в операциях с деньгами; использование `Decimal` и конвертация protobuf-типов `Quotation` (`units + nano / 1e9`).
* **Отказоустойчивость gRPC:** обработка `grpc.RpcError`, `ResourceExhausted` (Rate Limits) через экспоненциальный retry-backoff.
* **Событийная архитектура:** фоновые воркеры Celery Beat, синхронизированные с расписанием торгов Мосбиржи (MOEX).
* **Сложные вычисления:** матричная и статистическая обработка финансовых временных рядов на NumPy.
* **Zero-Trust Security & Encryption at Rest:** симметричное шифрование токенов инвестора в БД (`cryptography.fernet`) и межсервисная аутентификация по `X-Bot-Secret`.

## 3. Регламент Сократовского обучения (AI-Tutor Protocol)

Разработка ведется **авторским кодом пользователя**. ИИ-ассистент работает в строгом 3-этапном режиме ментора:

### Этап 1: Старт и Архитектурный каркас (Минимальная помощь)
* ИИ помогает спроектировать структуру сущностей БД (ER-диаграмму), конфигурацию окружения и базовый скелет проекта.
* Код дается только в виде минимальных концептуальных шаблонов (не более 5–10 строк).
* Основной фокус: понимание интерфейсов взаимодействия сервисов.

### Этап 2: Навигационный ментор (Информационный компас)
* **ИИ категорически запрещено писать готовый код за пользователя.**
* При вопросах вида *«Как сделать X?»* ИИ дает:
  1. Ссылки на конкретные разделы документации (официальная дока `tinkoff-invest-api`, Django ORM, gRPC).
  2. Названия точных классов, методов или модулей стандартной библиотеки (например: `tinkoff.invest.AsyncClient`, `InvestError`).
  3. Концептуальные наводящие вопросы: *«Подумай, что произойдет с сессией gRPC при разрыве TCP-соединения?»*.

### Этап 3: Строгий Tech Lead Code Reviewer (Контроль качества)
* Пользователь пишет код сам и отправляет на ревью.
* ИИ оценивает код по жестким критериям:
  * **Безопасность:** утечка токенов, отсутствие валидации.
  * **Производительность:** N+1 запросы в ORM, блокировка Event Loop в async-функциях, аллокация памяти в NumPy.
  * **Устойчивость к отказам (Resilience):** обработка Rate Limit (429 / ResourceExhausted), тайм-ауты, повторные попытки (retry backoff).

## 4. Пошаговый план разработки (Milestones)

1. **Milestone 1: Песочница и gRPC Hello World**
   * Получение Read-Only токена (или токена Sandbox).
   * Инициализация проекта через `uv`.
   * Первый асинхронный вызов через `tinkoff.invest.AsyncClient` (получение списка счетов и баланса).
   * Реализация корректного парсинга protobuf-денег (`MoneyValue` / `Quotation`) в Python `Decimal`.

2. **Milestone 2: Схема БД и Бэкенд**
   * Модели `InvestorUser`, `PortfolioSnapshot`, `Position` в Django с типами `DecimalField`.
   * Симметричное шифрование токенов инвестора в базе через `cryptography.fernet`.
   * Фоновая Celery-таска для регулярного сохранения слепка портфеля.

3. **Milestone 3: Аналитическое ядро на NumPy**
   * Векторизованный расчет максимальной просадки (Max Drawdown).
   * Расчет секторных долей портфеля и выявление перекосов.

4. **Milestone 4: Telegram-интерфейс (Aiogram 3)**
   * Авторизация пользователя по Telegram ID.
   * Команды `/portfolio` (быстрый срез) и `/risk` (глубокий аудит рисков).
   * Форматирование красивых отчетов с эмодзи.

5. **Milestone 5: Интеграция LLM (Gemini Pydantic)**
   * Подача численных метрик в промпт.
   * Генерация структурированного резюме от финансового аналитика.

6. **Milestone 6: Мультиброкерский агрегатор (Все банки и брокеры РФ)**
   * Унификация интерфейсов поставщиков данных через паттерн **Adapter / Factory Method** (`BaseBrokerAdapter`).
   * Интеграция API и брокерских шлюзов ведущих банков РФ: **СберИнвестиции**, **ВТБ Мои Инвестиции**, **Альфа-Инвестиции**, **БКС Мир Инвестиций**, **Финам Trade API**.
   * Поддержка автоматического импорта и парсинга стандартных брокерских отчётов (XML/Excel по ГОСТ ЦБ РФ) для счетов без открытого API.
   * Консолидированный дашборд капитала («All-in-One Net Worth»): кросс-брокерская аналитика, исключение дублирующих рисков и единый аудит диверсификации.
