# T-Invest Portfolio Auditor

Финтех-сервис и аналитический ассистент инвестора с интерфейсом в Telegram, работающий с официальным gRPC API Т-Банк Инвестиций (`tinkoff-invest-api`).

## Ключевые возможности

- **Интеграция с Т-Инвестициями**: прямое взаимодействие с API через бинарный протокол gRPC (protobuf).
- **Финансовая точность (Zero Float)**: все денежные вычисления производятся в `Decimal` с конвертацией структур `Quotation` (`units + nano / 1e9`).
- **Аналитика портфеля**: расчет структуры активов, концентрации, диверсификации и риска.
- **Telegram-бот (Aiogram 3)**: удобный просмотр баланса, счетов и портфельной аналитики.
- **Управление окружением**: поддержка безопасного хранения токенов и гибкой конфигурации.

## Стек технологий

- **Python 3.12+ / uv**
- **t-tech / tinkoff-investments** (gRPC / Protobuf)
- **Aiogram 3.x** (Telegram Bot)
- **Decimal** для исключения погрешностей округления с плавающей точкой

## Быстрый старт

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/31MaeStro13/T_INVEST.git
   cd T_INVEST
   ```

2. Установите зависимости:
   ```bash
   uv sync
   ```

3. Настройте переменные окружения:
   ```bash
   cp .env.example .env
   # Укажите ваш T_BANK_READ_ONLY_INVEST_TOKEN и BOT_TOKEN
   ```

4. Запустите тестовое получение счетов и баланса:
   ```bash
   uv run python hello_invest.py
   ```
